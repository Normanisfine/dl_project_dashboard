Four problems to orient the project

Two choices organize the field: whether the scene is static or moving, and whether observations come from one camera or several. Static reconstruction estimates geometry; dynamic reconstruction also needs motion and consistency over time.

Problem 1-1 · Static / one camera

Monocular static scene online reconstruction

Build and update a 3D scene as frames arrive from a moving camera. The challenge is to retain useful geometry over a long sequence without drift or ever-growing compute.

CUT3R · Official code

A continuous 3D perception model with persistent state: a starting point for geometry memory.

TTT3R · Official code

A state-update rule designed to improve CUT3R’s length generalization.

Problem 1-2 · Static / multiple views

Multi-view static scene online reconstruction

Fuse images from several viewpoints into shared geometry. For online use, the question is how to integrate new camera observations efficiently.

VGGT · Project & paper

A feed-forward model for predicting geometry, cameras, depth, and point tracks from multiple views.

Fast3R · Official code

Joint reconstruction of many images in one forward pass. These are multi-view references; online memory is a further research question.

Problem 2-1 · Dynamic / one camera

Single-view dynamic scene reconstruction

Recover changing geometry from a monocular video while separating scene motion from camera motion. Point tracking and temporal consistency matter because the same surface changes position over time.

V-DPM · Project, paper & code

Dynamic point maps extend video reconstruction to both geometry and 3D motion, building on VGGT.

Problem 2-2 · Dynamic / multiple cameras

Multi-view dynamic scene reconstruction

Combine camera views across time to reconstruct a moving scene. The challenge is to keep geometry, motion, and visibility consistent across both viewpoints and timestamps.

4D-LRM · Paper

A space-time reconstruction model for novel views and times from monocular or multi-view input.

DGGT · Official code & project

Feed-forward dynamic driving-scene reconstruction from sparse, unposed images, including motion and camera prediction.

Chosen direction · Problem 3

Sparse-view dynamic scene reconstruction with imagination

I want to reconstruct moving scenes from only a few camera views, using pretrained generative priors to imagine missing viewpoints and unseen content. This builds on the multi-view dynamic problem above, with much less observed evidence.

Less trainingGreater efficiencyConsistent geometry & motion

The main priority is to reuse pretrained models, minimize new training and per-scene optimization, and keep inference time and memory costs low. A possible route is frozen backbones, a small query decoder, and bounded geometry memory. This is a proposed direction, not a demonstrated result.

Diffuman4D · Imagination reference

Spatio-temporal diffusion generates consistent human views from sparse-view videos. It illustrates how a generative prior can fill missing observations.

Forge4D · Efficiency reference

Feed-forward human reconstruction and interpolation from uncalibrated sparse videos, without per-scene optimization.

Both references focus on humans; extending their ideas to general dynamic scenes remains an open question. Evaluate imagined views against held-out cameras and check geometry separately from image quality.
